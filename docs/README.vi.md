## 🛠️ Cách Nhập (Import) File Mẫu `.JSON` Vào n8n Chỉ Với 3 Click

1. **Khởi tạo máy chủ Cloud n8n 24/7:** Mở [**https://360rev-hub.github.io/hostinger**](https://360rev-hub.github.io/hostinger), chọn gói **Hostinger KVM 1** và chọn mẫu cài đặt sẵn 1-Click **`Applications → Ubuntu 24.04 with n8n`** trong hPanel.
2. **Tải file mẫu `.JSON` miễn phí:** Bấm vào nút **`📥 Tải File .JSON`** ở bảng trên hoặc truy cập [**https://360rev-hub.github.io/vi/blueprints/**](https://360rev-hub.github.io/vi/blueprints/).
3. **Nhập (Import) vào n8n trong 3 Click:** Trong giao diện n8n trên trình duyệt, bấm biểu tượng **`⋯` (góc trên bên phải) → `Import from File...`**, chọn file `.json` vừa tải, làm theo **3 Ghi Chú Màu Vàng** trên màn hình và gạt công tắc sang **Active**!
